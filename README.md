 StudyOS — учебная операционная система

 Описание проекта

StudyOS — учебный проект по дисциплине «Осуществление интеграции программных модулей».

Проект представляет собой симулятор операционной системы, разработанный на языке Python с использованием базы данных SQLite.

Система позволяет работать с пользователями, файлами, процессами и оперативной памятью через командную оболочку.

 Возможности

- Регистрация и авторизация пользователей.
- Разграничение прав доступа между администратором и обычным пользователем.
- Создание, чтение и удаление файлов.
- Просмотр списка файлов.
- Запуск и завершение процессов.
- Просмотр списка активных процессов.
- Выделение и освобождение оперативной памяти.
- Контроль лимита доступной памяти.
- Журналирование системных вызовов.
- Обработка ошибок при выполнении команд.

 Используемые технологии

- Python 3.10+
- SQLite
- Visual Studio Code
- Git и GitHub

 Установка и запуск

1. Скачать проект с GitHub или открыть папку `my_os`.
2. Убедиться, что установлен Python 3.10 или выше.
3. Открыть терминал в корневой папке проекта.
4. Инициализировать базу данных:

   `py src/db.py`

5. Запустить командную оболочку:

   `py src/shell.py`

После запуска появится приглашение StudyOS, в котором можно вводить команды.

 Основные команды

| Команда | Назначение |
|---|---|
| help | Показать список команд |
| login | Войти в систему |
| logout | Выйти из учётной записи |
| whoami | Показать текущего пользователя |
| create | Создать файл |
| cat | Прочитать файл |
| ls | Показать список файлов |
| delete | Удалить файл |
| run | Запустить процесс |
| ps | Показать процессы |
| kill | Завершить процесс |
| mem | Показать состояние памяти |
| logs | Показать журнал системных вызовов |
| exit | Завершить работу оболочки |

 Тестирование

Для проверки StudyOS разработаны модульные, функциональные, интеграционные и нагрузочные тесты.

Основные тестовые файлы:

- `test_db.py`
- `test_kernel_unit.py`
- `test_auth_unit.py`
- `test_fs_functional.py`
- `test_scheduler_functional.py`
- `test_syscalls_functional.py`
- `test_integration_full.py`
- `test_stress.py`

Для общего запуска тестов используется файл:

`tests/run_all.py`

На последнем подтверждённом запуске семь тестовых файлов завершились без ошибок. Результаты полного нагрузочного и регрессионного тестирования требуют окончательной проверки.
