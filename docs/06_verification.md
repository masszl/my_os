 Верификация требований

 NFR4 — хранение паролей

Пароли пользователей хранятся в виде SHA-256 хеша.

Результат: PASS

 NFR5 — разграничение прав

Обычный пользователь не может удалить файл, принадлежащий администратору.

Результат: PASS

 NFR6 — размер модулей

Модули проекта проверяются по количеству строк. Каждый основной модуль должен содержать не более 300 строк.

Результат: PASS

 NFR7 — журналирование

Системные вызовы записываются в таблицу syscalls_log. В журнале сохраняются имя вызова, аргументы, пользователь и статус выполнения.

Результат: PASS

 NFR8 — зависимости

Проект использует стандартные модули Python и собственные модули StudyOS. Внешняя СУБД не требуется, используется SQLite.

Результат: PASS

 NFR2 и NFR3

Основные операции файловой системы, процессов и памяти проверены автоматическими тестами.

Результат: PASS

 Итог

Основные нефункциональные требования проверены. Критических ошибок во время проверки не обнаружено.


 Проверка ошибочных сценариев

1. Неверный логин
Введены неправильные данные пользователя.
Система вывела сообщение об ошибке и продолжила работу.
Результат: PASS

2. Несуществующий файл
Выполнена команда cat /missing.txt.
Система сообщила, что файл пуст или не существует.
Результат: PASS

3. Несуществующий процесс
Выполнена команда kill 99999.
Система сообщила, что процесс завершить невозможно.
Результат: PASS

4. Проверка прав доступа
Пользователь user попытался удалить файл администратора /admin_file.txt.
Удаление было запрещено.
Результат: PASS

Все ошибочные сценарии обработаны без аварийного завершения программы.
