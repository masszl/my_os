 Интеграционные сценарии StudyOS

 IS-01. Создание файла через Shell

Участвующие модули: shell, syscalls, fs, db.

Шаги:
1. Войти в систему под администратором.
2. Выполнить команду create.
3. Указать путь /is01.txt.
4. Ввести содержимое hello.
5. Проверить наличие файла.

Ожидаемый результат:
Файл успешно создаётся, сохраняется в базе данных.
В журнале появляется запись sys_create_file со статусом OK.

 IS-02. Чтение файла через Shell

Участвующие модули: shell, syscalls, fs, db.

Шаги:
1. Создать файл /is02.txt с текстом StudyOS.
2. Выполнить команду cat /is02.txt.
3. Проверить выведенный текст.

Ожидаемый результат:
На экран выводится StudyOS.
В журнале появляется запись sys_read_file.

 IS-03. Запрет удаления чужого файла

Участвующие модули: shell, syscalls, auth, fs, db.

Шаги:
1. Администратор создаёт файл /is03.txt.
2. Войти под обычным пользователем.
3. Выполнить команду delete /is03.txt.
4. Проверить наличие файла.

Ожидаемый результат:
Удаление запрещено.
Файл остаётся в системе.
В журнале появляется запись DENIED.

 IS-04. Запуск процесса

Участвующие модули: shell, syscalls, scheduler, kernel, db.

Шаги:
1. Войти под администратором.
2. Выполнить команду run editor.
3. Проверить список процессов командой ps.
4. Проверить использование памяти командой mem.

Ожидаемый результат:
Создаётся процесс editor с уникальным PID.
Процесс появляется в списке.
Использованная память увеличивается.
В журнале появляется запись sys_exec со статусом OK.

 IS-05. Завершение процесса

Участвующие модули: shell, syscalls, auth, scheduler, kernel, db.

Шаги:
1. Запустить процесс editor.
2. Запомнить его PID.
3. Выполнить команду kill с указанным PID.
4. Проверить список процессов и память.

Ожидаемый результат:
Процесс удаляется из списка.
Занятая им память освобождается.
В журнале появляется запись sys_kill со статусом OK.

 IS-06. Полный сценарий администратора

Участвующие модули: все основные модули StudyOS.

Шаги:
1. Войти под администратором.
2. Создать файл через create.
3. Прочитать файл через cat.
4. Запустить программу через run.
5. Посмотреть процессы через ps.
6. Завершить процесс через kill.
7. Проверить память через mem.
8. Завершить работу командой exit.

Ожидаемый результат:
Все разрешённые операции выполняются успешно.
Файлы и процессы корректно обрабатываются.
Системные вызовы фиксируются в журнале.

 IS-07. Полный сценарий обычного пользователя

Участвующие модули: shell, syscalls, auth, fs, scheduler, kernel, db.

Шаги:
1. Войти под обычным пользователем.
2. Создать собственный файл.
3. Попытаться удалить файл администратора.
4. Запустить собственный процесс.
5. Попытаться завершить процесс через kill.
6. Завершить работу командой exit.

Ожидаемый результат:
Создание собственного файла разрешено.
Удаление чужого файла запрещено.
Запуск процесса разрешён.
Команда kill запрещена обычному пользователю.
Отказы фиксируются в журнале со статусом DENIED.
