 Отчёт о разработке — День 6

 1. Цель работы

Цель работы — объединить разработанные модули StudyOS, проверить их совместную работу и провести итоговое тестирование системы.

 2. Интеграция модулей

В проекте были объединены основные модули:

- db.py — работа с базой данных SQLite;
- kernel.py — ядро системы и управление памятью;
- auth.py — регистрация, авторизация и проверка прав;
- fs.py — работа с файлами;
- scheduler.py — управление процессами;
- syscalls.py — системные вызовы;
- shell.py — командная оболочка.

Модули работают совместно через системные вызовы.

 3. Командная оболочка

В StudyOS реализованы команды:

help
echo
whoami
login
logout
create
cat
ls
delete
run
ps
kill
mem
logs
exit

Через оболочку можно войти в систему, работать с файлами, запускать процессы, просматривать память и журнал системных вызовов.

 4. Интеграционное тестирование

Были проверены:

- создание файла;
- чтение файла;
- защита от создания дубликата;
- проверка прав на удаление;
- создание процесса;
- завершение процесса;
- ограничение памяти.

Интеграционные проверки прошли успешно.

 5. Проверка ошибочных ситуаций

Проверены следующие ситуации:

1. Вход с неправильным логином и паролем.
2. Попытка чтения несуществующего файла.
3. Попытка завершить несуществующий процесс.
4. Попытка обычного пользователя удалить файл администратора.

Во всех случаях система продолжила работу без аварийного завершения.

 6. Верификация требований

Проверено хранение паролей в виде SHA-256.

Проверено разграничение прав пользователей.

Проверено журналирование системных вызовов.

Основные модули проекта содержат менее 300 строк.

Для хранения данных используется SQLite.

Файловая система, процессы и память проверены во время интеграции.

 7. Исправленные ошибки

Во время разработки была обнаружена проблема с повторением PID после перезапуска программы.

Счётчик процессов был изменён так, чтобы учитывать уже существующие процессы в базе данных.

Также была исправлена работа с сохранением состояния памяти в таблице memory_state.

 8. Диаграммы

Созданы две диаграммы:

- 06_dataflow_create_file.png — создание файла;
- 06_dataflow_run_process.png — запуск процесса.

 9. Результат

Основные компоненты StudyOS объединены в одну систему.

Работают авторизация, файловая система, процессы, управление памятью, системные вызовы и командная оболочка.

Система обрабатывает основные ошибочные ситуации без аварийного завершения.
