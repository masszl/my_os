 Архитектура ОС

1. Состав модулей

В MyOS программа разделена на несколько модулей. Каждый модуль отвечает за свою часть работы системы.

shell.py — командная оболочка, через которую пользователь вводит команды.

syscalls.py — содержит системные вызовы и передаёт команды дальше в систему.

kernel.py — основная часть системы, которая управляет работой остальных модулей.

scheduler.py — отвечает за работу с процессами и их выполнение.

memory.py — отвечает за выделение и освобождение памяти.

fs.py — отвечает за работу с файлами.

auth.py — отвечает за пользователей, вход в систему и проверку прав.

db.py — отвечает за подключение и работу с базой данных SQLite.

 2. Системные вызовы

В MyOS будут использоваться следующие системные вызовы:

'sys_login(login: str, password: str) -> bool' — вход пользователя в систему.

'sys_logout() -> bool' — выход из текущей учётной записи.

'sys_whoami() -> str'— показывает имя текущего пользователя.

'sys_create_file(path: str, content: str) -> int' — создаёт новый файл и возвращает его id.

'sys_read_file(path: str) -> str' — читает содержимое файла.

'sys_delete_file(path: str) -> bool' — удаляет файл.

'sys_list_files(path: str) -> list' — показывает список файлов.

'sys_exec(name: str) -> int' — запускает процесс и возвращает его id.

'sys_ps() -> list' — показывает список процессов.

'sys_kill(pid: int) -> bool' — завершает выбранный процесс.

'sys_mem_alloc(size: int) -> int' — выделяет память процессу.

'sys_logs(limit: int) -> list' — показывает последние записи журнала.

'sys_shutdown() -> bool' — завершает работу системы.


 Контракты системных вызовов

 sys_login

Предварительное условие: пользователь с таким логином есть в базе.

Постусловие: система возвращает True при успешном входе или False при ошибке.

Побочный эффект: информация о вызове записывается в 'syscalls_log'


 sys_create_file

Предварительное условие: пользователь вошёл в систему.

Постусловие: создаётся файл и возвращается его id.

Побочный эффект: новый файл появляется в базе и вызов записывается в журнал.


 sys_exec

Предварительное условие: пользователь вошёл в систему.

Постусловие: создаётся новый процесс и возвращается его id.

Побочный эффект: процесс добавляется в систему, а вызов записывается в журнал.
