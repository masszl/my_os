 Функциональные тесты StudyOS

 1. Файловая система fs.py

 FT-01: Создание файла
Функция: create_file()
Проверка: создать файл /f01.txt с содержимым hello.
Ожидаемый результат: файл создан, возвращается id больше 0.

 FT-02: Создание дубликата
Функция: create_file()
Проверка: повторно создать файл с одинаковым путём.
Ожидаемый результат: возвращается -1, дубликат не создаётся.

 FT-03: Чтение файла
Функция: read_file()
Проверка: прочитать содержимое существующего файла.
Ожидаемый результат: возвращается записанный текст.

 FT-04: Чтение отсутствующего файла
Функция: read_file()
Проверка: прочитать /missing.txt.
Ожидаемый результат: возвращается пустая строка.

 FT-05: Изменение файла
Функция: write_file()
Проверка: изменить содержимое существующего файла.
Ожидаемый результат: при чтении возвращается новый текст.

 FT-06: Удаление файла
Функция: delete_file()
Проверка: удалить существующий файл.
Ожидаемый результат: файл больше не находится в базе данных.

 FT-07: Список файлов
Функция: list_files()
Проверка: создать два файла и получить список.
Ожидаемый результат: оба файла присутствуют в списке.

 FT-08: Получение владельца
Функция: get_owner()
Проверка: получить владельца файла администратора.
Ожидаемый результат: возвращается admin.

 FT-09: Владелец отсутствующего файла
Функция: get_owner()
Проверка: запросить владельца несуществующего файла.
Ожидаемый результат: возвращается None.

 FT-10: Информация о файле
Функция: get_file_info()
Проверка: получить информацию о существующем файле.
Ожидаемый результат: возвращается запись с путём, содержимым и владельцем.


 2. Планировщик scheduler.py

 FT-11: Создание процесса
Функция: create_process()
Проверка: создать процесс test_app от пользователя admin.
Ожидаемый результат: возвращается PID больше 0.

 FT-12: Превышение лимита памяти
Функция: create_process()
Проверка: попытаться создать процесс с потреблением 5000 единиц памяти.
Ожидаемый результат: возвращается -1, процесс не создаётся.

 FT-13: Список процессов
Функция: list_processes()
Проверка: создать два процесса и получить список.
Ожидаемый результат: оба процесса присутствуют в списке.

 FT-14: Получение процесса по PID
Функция: get_process()
Проверка: найти существующий процесс по PID.
Ожидаемый результат: возвращается информация о нужном процессе.

 FT-15: Несуществующий PID
Функция: get_process()
Проверка: запросить процесс с PID 99999.
Ожидаемый результат: возвращается None.

 FT-16: Освобождение памяти
Функция: terminate_process()
Проверка: создать процесс с памятью 50, затем завершить его.
Ожидаемый результат: использованная память уменьшается на 50.

 FT-17: Завершение несуществующего процесса
Функция: terminate_process()
Проверка: завершить процесс с PID 99999.
Ожидаемый результат: возвращается False.

 FT-18: Планирование Round Robin
Функция: schedule_round_robin()
Проверка: создать два процесса и вызвать планировщик.
Ожидаемый результат: один процесс получает состояние running.

 FT-19: Подсчёт процессов
Функция: process_count()
Проверка: создать несколько процессов и проверить их количество.
Ожидаемый результат: возвращается количество процессов в базе данных.
