 Тест-план учебной операционной системы

 1. Введение

Цель тестирования — проверить, что учебная операционная система работает правильно и основные модули взаимодействуют без ошибок.

Тестируется проект StudyOS, разработанный на Python с использованием SQLite.

 2. Объём тестирования

В тестирование входят:

- модульные тесты db.py, kernel.py и auth.py;
- проверка файловой системы;
- проверка процессов и памяти;
- проверка авторизации и прав пользователей;
- интеграционное тестирование модулей;
- проверка основных команд оболочки.

Не входят:

- тестирование под высокой нагрузкой;
- тестирование на реальном серверном оборудовании;
- проверка графического интерфейса.

 3. Виды тестирования

Будут использоваться:

- модульное тестирование;
- функциональное тестирование;
- интеграционное тестирование;
- системное тестирование;
- регрессионное тестирование.

 4. Ресурсы

Инструменты: VS Code, Python 3.10+, SQLite, SQLite Viewer, Git.

Документация проекта находится в папке docs.

Тестовые данные создаются во время выполнения тестов.

 5. Расписание

День 7 — разработка тест-плана, тест-кейсов и модульных тестов.

День 8 — функциональное и интеграционное тестирование.

День 9 — системное и регрессионное тестирование, итоговый протокол.

 6. Критерии начала и окончания

Критерии начала:

- основные модули разработаны;
- интеграционные тесты работают;
- база данных создаётся.

Критерии окончания:

- все модульные тесты пройдены;
- все функциональные тесты пройдены;
- все интеграционные тесты пройдены;
- найденные дефекты оформлены;
- критические ошибки отсутствуют.
