 Чек-лист тестирования StudyOS

 Авторизация

- [ ] Пользователь может войти с правильным логином и паролем.
- [ ] Неверный пароль отклоняется.
- [ ] Несуществующий пользователь не может войти.
- [ ] Команда whoami показывает текущего пользователя.
- [ ] Команда logout завершает текущую сессию.

 Файловая система

- [ ] Команда create создаёт файл.
- [ ] Команда cat выводит содержимое файла.
- [ ] Команда ls показывает список файлов.
- [ ] Нельзя создать два файла с одинаковым путём.
- [ ] Пользователь не может удалить чужой файл.
- [ ] Администратор может удалить файл.

 Процессы

- [ ] Команда run создаёт процесс.
- [ ] Каждый процесс получает PID.
- [ ] Команда ps показывает список процессов.
- [ ] Команда kill завершает существующий процесс.
- [ ] Попытка завершить несуществующий PID обрабатывается без ошибки.

 Память

- [ ] При запуске процесса выделяется память.
- [ ] При завершении процесса память освобождается.
- [ ] Нельзя выделить памяти больше установленного лимита.
- [ ] Команда mem показывает использованную память.
- [ ] Команда mem показывает свободную память.

 Командная оболочка

- [ ] Команда help показывает список команд.
- [ ] Команда echo выводит введённый текст.
- [ ] Неизвестная команда обрабатывается без завершения программы.
- [ ] Команда logs показывает журнал системных вызовов.
- [ ] Команда exit корректно завершает StudyOS.
