 BUG-01: Попытка создать дубликат файла

**Серьёзность:** средняя

**Приоритет:** средний

**Статус:** закрыт (не воспроизводится)

**Шаги воспроизведения:**

1. Создать файл /dup.txt с содержимым "a".
2. Повторно создать файл /dup.txt с содержимым "b".
3. Проверить результат второго вызова.

**Ожидаемый результат:** второй файл с таким же путём не создаётся, функция возвращает -1.

**Фактический результат:** второй вызов возвращает -1, дубликат файла не создаётся.

**Причина:** в fs.create_file выполняется проверка существования файла с таким путём.

**Решение:** дефект не обнаружен, система работает корректно.
