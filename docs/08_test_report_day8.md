 Отчёт по тестированию StudyOS — День 8

 1. Цель работы

Провести функциональное и интеграционное тестирование учебной операционной системы StudyOS. Проверить корректность работы основных модулей, их взаимодействие, обработку ошибок и соблюдение прав доступа.

 2. Тестируемые модули

- fs.py — файловая система.
- scheduler.py — управление процессами.
- syscalls.py — системные вызовы.
- auth.py — авторизация и права доступа.
- kernel.py — управление памятью.
- db.py — работа с базой данных.
- shell.py — командный интерфейс.

 3. Функциональное тестирование

Для проверки отдельных модулей подготовлены следующие файлы:

- tests/test_fs_functional.py
- tests/test_scheduler_functional.py
- tests/test_syscalls_functional.py

|---|---:|---|

| Планировщик процессов | 9 | Требует подтверждения |
| Системные вызовы | 11 | Требует подтверждения |
| Итого | 30 | Требует подтверждения |

Проверяются создание, чтение, изменение и удаление файлов, управление процессами, выделение памяти, права доступа и журналирование операций.

 4. Интеграционное тестирование

Создан файл tests/test_integration_full.py, содержащий 10 интеграционных тестов.

Проверяются следующие сценарии:

- IS-01 — создание файла.
- IS-02 — чтение файла.
- IS-03 — запрет удаления чужого файла.
- IS-04 — запуск процесса.
- IS-05 — завершение процесса.
- IS-06 — действия администратора.
- IS-07 — действия обычного пользователя.
- IS-08 — журнал системных вызовов.
- IS-09 — журнал отказов.
- IS-10 — очистка ресурсов.

При первоначальном запуске обнаружена ошибка в тесте IS-07: проверка запрета завершения процесса обычным пользователем завершилась AssertionError.

После этого был изменён модуль auth.py. Повторный успешный запуск полного набора тестов пока не подтверждён.

 5. Обнаруженные ошибки

BUG-08-01 — некорректный результат проверки операции sys_kill() для обычного пользователя.

Ошибка обнаружена при выполнении интеграционного теста IS-07.

Для устранения проблемы обновлена функция check_permission() в модуле auth.py.

Текущий статус: требуется повторное тестирование.

Подробности приведены в docs/08_bug_reports.md.
