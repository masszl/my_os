 BUG-08-01. Обычный пользователь может завершить процесс

**Модуль:** auth.py / syscalls.py

**Серьёзность:** High

**Приоритет:** High

**Предусловия:**
- В системе зарегистрирован обычный пользователь.
- Создан процесс с действующим PID.

**Шаги воспроизведения:**
1. Запустить интеграционный тест IS-07.
2. Войти под обычным пользователем.
3. Создать процесс.
4. Вызвать sys_kill() от имени этого пользователя.

**Ожидаемый результат:**
Операция запрещена. Функция возвращает False, процесс остаётся в системе, в журнале появляется DENIED.

**Фактический результат:**
Проверка assert sys_kill(pid, TEST_USER) is False завершилась ошибкой AssertionError.

**Причина:**
Требуется проверить логику проверки прав в auth.py, роль тестового пользователя в базе данных и вызов check_permission() в syscalls.py.

**Исправление:**
Проверить права доступа к операции kill. Для роли user операция должна быть запрещена.

**Статус:** Требует повторной проверки после изменения auth.py.
