 Журнал интеграции

 Сквозной сценарий

1. Команда help — список команд отображается.
2. Команда echo — текст выводится корректно.
3. Команда whoami — текущий пользователь определяется.
4. Вход под admin — выполнен успешно.
5. Создание файлов — работает.
6. Команда ls — файлы отображаются.
7. Команда cat — содержимое файла читается.
8. Запуск editor — процесс создаётся.
9. Запуск browser — процесс создаётся.
10. Команда ps — процессы отображаются.
11. Команда kill — процесс editor завершён.
12. Команда mem — состояние памяти отображается.
 Результат

Основные модули работают совместно. Файловая система, планировщик, ядро, системные вызовы и оболочка связаны между собой.

 Найденные ошибки

Во время интеграции была обнаружена проблема с повторяющимися PID процессов.

Причина: после перезапуска системы счётчик PID начинался заново.

Исправление: при запуске Kernel счётчик устанавливается на основе уже существующих процессов.

Также была исправлена проблема с сохранением состояния памяти в таблице memory_state.
