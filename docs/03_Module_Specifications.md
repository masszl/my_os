 Спецификации модулей

 1. Модуль db.py

 Назначение

Модуль обеспечивает подключение к базе данных SQLite, создание таблиц при первом запуске и предоставление соединения другим модулям.

 Публичный интерфейс

- get_connection() -> sqlite3.Connection — возвращает соединение с базой.
- init_db() -> None — создаёт таблицы, если их нет.
- execute_query(sql: str, params: tuple) -> list — выполняет запрос и возвращает результат.

 Внутренние зависимости

Модуль не зависит от других модулей проекта. Использует стандартный модуль sqlite3.

 Обработка ошибок

- sqlite3.OperationalError — если база заблокирована, повторить попытку через 100 мс.
- sqlite3.IntegrityError — если нарушено ограничение UNIQUE, вернуть None.

 Побочные эффекты

- Создание файла db/os.sqlite при первом запуске.
- Создание таблиц`users, processes, files, syscalls_log.
  

 2. Модуль syscalls.py

 Назначение

Модуль предоставляет единый интерфейс для оболочки. Каждая функция проверяет аргументы, вызывает соответствующую логику ядра и записывает вызов в журнал.

 Публичный интерфейс

- `log_syscall(name, args, user, status) -> None
- `sys_login(login, password, current_user) -> bool
- `sys_logout(current_user) -> bool
- `sys_whoami(current_user) -> str
- `sys_create_file(path, content, current_user) > int
- `sys_read_file(path, current_user) -> str
- `sys_delete_file(path, current_user) -> boo
- `sys_list_files(path, current_user) -> list
- `sys_exec(name, current_user) -> int
- `sys_ps(current_user) -> list
- `sys_kill(pid, current_user) -> bool
- `sys_mem_alloc(size, current_user) -> int
- `sys_logs(limit, current_user) -> list
- `sys_shutdown(current_user) -> bool

 Внутренние зависимости

- db.py — для записи в syscalls_log`.
- `kernel.py — для вызова основной логики, которая будет реализована на следующих занятиях.

 Обработка ошибок

- Если пользователь не авторизован, `sys_create_file возвращает -1.
- Если файл не найден, `sys_read_file возвращает пустую строку.
- Если pid не существует, `sys_kill возвращает False.

 Побочные эффекты

Каждый вызов записывает строку в таблицу `syscalls_log с полями: имя вызова, аргументы, пользователь, статус и время.

 Описание требований

**NFR-1:** Время обработки системного вызова ≤ 50 мс.  
Модуль syscalls.py` должен обеспечивать быстрое выполнение системных вызовов.

**NFR-2:** ОС выдерживает 10 одновременных процессов.  
Модуль scheduler.py` отвечает за управление процессами и должен поддерживать работу нескольких процессов.

**NFR-3:** Ошибка в процессе не роняет ядро.  
Модуль kernel.py` должен обрабатывать ошибки процессов без остановки всей системы.

**NFR-4:** Пароли хранятся в виде хэша SHA-256.  
Модуль auth.py должен вычислять хэш пароля и сохранять его в поле password_hash таблицы `users.

**NFR-5:** User не может удалить файл Admin.  
Модуль `fs.py должен проверять права пользователя перед удалением файла.

**NFR-6:** Код разбит на модули ≤ 300 строк.  
Файлы проекта должны быть разделены на небольшие модули размером не более 300 строк.

**NFR-7:** Все системные вызовы логируются.  
Модуль syscalls.p записывает информацию о системных вызовах в таблицу syscalls_log`.

**NFR-8:** ОС работает без внешних СУБД.  
Модуль `db.py использует встроенную базу данных SQLite.
