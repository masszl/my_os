# Речь для защиты проекта StudyOS

Здравствуйте! Сегодня я хочу представить свой проект StudyOS — учебную модель операционной системы, которую я разработал на языке Python.

**Целью моей работы** было создание программы, которая имитирует некоторые основные функции операционной системы: работу с пользователями, файлами, процессами и оперативной памятью.

Для разработки я использовал Python, базу данных SQLite и среду Visual Studio Code. Также применял Git для сохранения изменений в проекте.

Сначала я определил требования к системе и разработал её архитектуру. Затем разделил проект на семь основных модулей, чтобы каждый отвечал за свою задачу.

Например, модуль `auth.py` отвечает за авторизацию пользователей, `fs.py` — за работу с файлами, `scheduler.py` — за управление процессами, а `kernel.py` — за управление памятью.

Для взаимодействия с системой я создал командную оболочку. Пользователь может вводить команды, а программа обрабатывает их и выводит результат.

Например, команда `create` позволяет создать файл, `cat` — прочитать его содержимое, `run` — запустить процесс, а `ps` — посмотреть список процессов.

Также в проекте предусмотрено разграничение прав доступа. Есть администратор и обычный пользователь. Администратор обладает расширенными правами, а для обычного пользователя действуют некоторые ограничения.

Для хранения информации я использовал SQLite. В базе данных созданы пять таблиц, в которых хранятся пользователи, файлы, процессы, журнал системных вызовов и состояние памяти.

**Отдельное внимание я уделил тестированию.** Я проверял работу отдельных модулей и их взаимодействие. Для этого были написаны модульные, функциональные и интеграционные тесты, а также подготовлены нагрузочные и регрессионные проверки.

Во время разработки возникали ошибки, связанные с импортом модулей, структурой базы данных и освобождением памяти после завершения процессов. Эти проблемы я постепенно исправлял и повторно проверял работу программы.

В результате мне удалось создать учебную модель операционной системы, которая позволяет выполнять основные команды и сохранять информацию в базе данных.

Конечно, StudyOS не является полноценной операционной системой. Это учебный симулятор, который помогает понять, как взаимодействуют программные компоненты.

В дальнейшем проект можно улучшить: добавить полноценную структуру каталогов, новые команды и более подробную обработку ошибок.

**В заключение** хочу сказать, что во время практики я получил опыт разработки на Python, работы с базами данных, тестирования и организации программного проекта.

Спасибо за внимание! Я готов ответить на вопросы.
